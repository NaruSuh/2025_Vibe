## 1. 사용자 페르소나 분석

### 1.1 페르소나별 니즈 매트릭스

| 페르소나 | 주요 고민 | 현재 앱 해결 | 미해결 영역 |
|----------|-----------|--------------|-------------|
| **학부생** (탐색 단계) | "어떤 분야가 나한테 맞을까?" | 동영상 탐색 ✅ | 로드맵, 진로 정보 |
| **지원 준비생** | "어느 교수님께 지원할까?" | 교수 검색/비교 ✅ | 논문, 데드라인, SOP |
| **대학원생** | "연구 트렌드가 뭐지?" | 동영상, ChatGPT ✅ | 논문 추적, 학회 정보 |
| **취준생/초기경력** | "면허는? 취업은?" | ❌ | 면허요건, 커리어 경로 |

### 1.2 심리학도의 실제 여정

```
[학부 2-3학년]          [지원 준비]           [대학원]              [졸업 후]
     │                     │                    │                    │
     ▼                     ▼                    ▼                    ▼
"어떤 분야?"          "어느 교수?"         "논문 주제?"         "면허? 취업?"
"연구 경험?"          "SOP 어떻게?"        "최신 트렌드?"       "개원 vs 취업?"
"현실적 진로?"        "경쟁력 있나?"       "협업자 찾기"        "어느 주?"
```

### 1.3 단계별 상세 고통점

#### Pre-Application Phase (지원 1-2년 전)
- "어떤 세부 전공이 나에게 맞을까?"
- "어떤 연구 경험이 필요한가?"
- "연구 기회는 어떻게 찾는가?"
- "현실적인 커리어 결과는?"

#### Application Phase (지원 6-12개월 전)
- "내 관심사에 맞는 프로그램은?"
- "내 연구 관심사와 맞는 교수는?"
- "이 프로그램에 내가 경쟁력 있나?"
- "좋은 SOP는 어떻게 쓰는가?"
- "데드라인은 언제?"
- "교수에게 먼저 연락해야 하나?"

#### Post-Admission Phase (합격 후)
- "어느 오퍼를 수락해야 하나?"
- "프로그램 시작 전 준비할 것은?"
- "미리 읽어야 할 것은?"

#### During Graduate School (대학원 중)
- "문헌을 어떻게 따라잡나?"
- "협업자는 어떻게 찾나?"
- "인턴십 준비는 어떻게?"
- "종합시험 대비는?"

#### Post-Graduation (졸업 후)
- "어떻게 면허를 취득하나?"
- "어떤 취업 기회가 있나?"
- "개인 클리닉은 어떻게 시작하나?"

## 3. Tier 1: 즉시 구현 가능, 높은 가치

### 3.1 SOP/연구계획서 작성 도우미

**현재 상태:**
```
ChatGPT로 교수 정보 질문만 가능
```

**추가 기능:**
```
"이 교수님께 지원하는 SOP 초안 작성해줘"
- 연구 관심사 매칭 분석
- 강점/약점 피드백
- 문장별 개선 제안
```

**구현 방식:**
- ChatGPT 프롬프트 확장
- 새로운 질문 템플릿 추가
- SOP 구조 가이드 제공

**예상 구현 시간:** 1-2일

---

### 3.2 유사 연구자 추천

**기능 설명:**
```
"이 교수님과 비슷한 연구를 하는 다른 교수"
- 연구 키워드 기반 유사도 계산
- "Depression + CBT" 관심사 → 관련 교수 5명 추천
```

**구현 방식:**
- 기존 professors_database 활용
- 키워드 기반 코사인 유사도 계산
- TF-IDF 또는 간단한 Jaccard 유사도

**예상 구현 시간:** 2-3일

---

### 3.3 분야별 학습 로드맵

**기능 설명:**
```
"임상심리학 박사과정 준비 로드맵"
- 추천 교재 목록
- 필수 선수과목
- 추천 동영상 순서
- 타임라인 (6개월/1년/2년)
```

**구현 방식:**
- 정적 데이터 + ChatGPT 개인화
- 분야별 로드맵 템플릿

**예상 구현 시간:** 2-3일

---

### 3.4 논문 검색 연동

**기능 설명:**
```
교수 프로필에 "최근 논문 5편" 표시
- Semantic Scholar API (무료, 제한 없음)
- Google Scholar 프로필 링크
```

**구현 방식:**
- Semantic Scholar API 연동
- 교수명 기반 논문 검색
- 캐싱으로 API 호출 최소화

**예상 구현 시간:** 3-4일

## 6. Deep Research: IT 기술 활용 분석

### 6.1 기술이 인간을 대체할 수 있는 영역

| 영역 | 인간 한계 | IT 해결 |
|------|-----------|---------|
| **대규모 문헌 분석** | 수백 편 논문 읽기 불가 | NLP로 수만 편 분석 |
| **패턴 발견** | 개인 경험에 의존 | ML로 숨겨진 패턴 발견 |
| **실시간 매칭** | 수작업 비교 | 알고리즘 즉시 매칭 |
| **데드라인 추적** | 망각, 누락 | 자동 알림 |
| **네트워크 시각화** | 불가능 | 그래프 알고리즘 |

### 6.2 High-Impact, Tech-Solvable Problems

1. **Literature Discovery & Tracking**
   - Problem: "관련 논문을 어디서 시작해야 할지 모르겠다"
   - Solution: 논문 추천 엔진, 읽기 목록 생성기
   - Tech: Semantic Scholar API, citation network analysis

2. **Faculty-Student Fit Matching**
   - Problem: "이 교수의 연구가 내 관심사와 정말 맞는지 모르겠다"
   - Solution: AI 기반 연구 관심사 매칭 + 설명
   - Tech: NLP on research descriptions, keyword embedding similarity

3. **Application Strategy Optimization**
   - Problem: "내 프로필로 어떤 프로그램에 지원해야 하나?"
   - Solution: 프로필 분석기 + 프로그램 추천
   - Tech: Rule-based system or ML model

4. **Writing Assistance**
   - Problem: "내 SOP가 충분히 좋은가?"
   - Solution: SOP 분석기 + 구체적 피드백
   - Tech: GPT-4 with structured prompts

5. **Research Skill Gap Analysis**
   - Problem: "어떤 스킬을 배워야 하나?"
   - Solution: 스킬 비교 (당신 vs 교수/프로그램 요구)
   - Tech: Skill extraction + gap analysis

## 7. Game-Changer 기능 상세 (Tier S)

### 7.1 Research Fit Analyzer (연구 적합도 분석기)

**아키텍처:**
```
[학생 입력]                    [AI 분석]                      [출력]
─────────────────────────────────────────────────────────────────────
• 관심 연구 분야              →  키워드 추출              →  매칭 점수
• 과거 연구 경험              →  개념 임베딩              →  구체적 중복 영역
• 작성한 글/에세이 (선택)     →  186개 대학 교수 비교     →  차이점/보완점
                                                          →  최근 관련 논문
                                                          →  질문 제안
```

**왜 IT가 필수인가:**
- 인간: 교수 10명 연구 분야 비교하는데 수 시간
- AI: 500명+ 교수를 10초에 분석, 유사도 계산

**구현 기술:**
- Sentence-BERT / OpenAI Embeddings
- 코사인 유사도 + 키워드 교집합
- Semantic Scholar API로 최근 논문 연동

**예상 구현 시간:** 1-2주

---

### 7.2 Research Gap Finder (연구 공백 발견기)

**출력 예시:**
```
"우울증 + 청소년 + 디지털 치료" 조합의 연구 현황:
┌─────────────────────────────────────────┐
│ 📈 발표 논문 수: 127편 (최근 5년)       │
│ 📊 성장률: +45%/년                      │
│ 🔥 핫 토픽: smartphone intervention     │
│ ⚠️ 공백 영역: "한국 청소년 대상 연구"   │
│ 💡 잠재 기회: "K-CBT 앱 효과성 검증"    │
└─────────────────────────────────────────┘
```

**왜 IT가 필수인가:**
- 수만 편의 논문을 분석해 "연구가 부족한 영역" 식별
- 인간은 절대 불가능한 규모의 문헌 분석

**구현 기술:**
- Semantic Scholar API (무료, 2억+ 논문)
- Topic Modeling (LDA, BERTopic)
- Citation network analysis

**예상 구현 시간:** 2-3주

                    [Dr. Smith]

**예상 구현 시간:** 1-2주

## 8. Killer Feature 제안

### 8.1 통합 솔루션: Research Fit Analyzer + Smart Question Generator

**사용자 플로우:**
```
[학생]                      [앱]                         [결과]
───────────────────────────────────────────────────────────────
"나는 청소년 우울증    →   500명 교수 분석    →   "Top 10 매칭 교수"
 + 디지털 치료에                                  + 각 교수별:
 관심 있어"                                         - 매칭 점수
                                                    - 구체적 이유
                                                    - 최근 논문 3편
                                                    - 추천 질문 3개
                                                    - SOP 포인트
```

### 8.2 Smart Question Generator 상세

**입력:** 교수 정보 (Dr. Sarah Johnson - UCLA)

**처리:**
```
📄 최근 논문 분석 (최근 3년, 12편):
   • 주요 주제: PTSD, cognitive processing, fMRI
   • 방법론: RCT, neuroimaging
   • 최신 연구: "Trauma memory reconsolidation" (2024)
```

**출력:**
```
❓ 추천 질문:
   1. "Your 2024 paper on reconsolidation - how might this
      inform clinical interventions beyond CPT?"

   2. "I noticed a shift toward neuroimaging methods since 2022.
      Is your lab planning more translational research?"

   3. "Given the replication concerns in trauma research,
      how does your lab approach study design?"

⚠️ 피해야 할 질문:
   • 홈페이지에 이미 있는 기본 정보
   • 2019년 이전 오래된 연구 관련
```

### 8.3 SOP 전략 분석기 상세

**입력:** 학생 SOP 초안

**출력:**
```
[분석 결과]
─────────────────────────────────────
✅ 강점:
   • 연구 경험 구체적 (line 12-18)
   • 해당 교수 연구 언급 (line 24)

⚠️ 개선 필요:
   • "왜 이 프로그램인가" 불명확 (line 5-8)
   • 연구 목표가 너무 광범위 (line 30-35)
   • 이 교수의 최근 연구(2024) 미반영

📊 경쟁력 점수: 72/100
   • 비슷한 수준 SOP의 합격률: ~35%

💡 구체적 수정 제안:
   • Line 30: "트라우마 치료" → "PTSD의 인지적 재평가 기제"
   • 추가 권장: Dr. X의 2024년 논문 "..." 언급
```
